QuireTWM arranges windows in horizontal columns on an infinite strip. Written in C++20 and Lua 5.4 with Direct2D hardware rendering.

Ribbon Layout

Windows stand side by side in dynamic columns. New windows insert next to your focus without splitting screen space into tiny boxes.

Vertical Workspaces

Workspaces stack on the vertical axis. Desktops slide up and down with spring physics, keeping layouts isolated.

Direct2D Overlay

Hardware accelerated render target handles window outlines, HUD pills and the task switcher without input latency.

Lua Configuration

Edit colors, margins, keys and window rules in pure Lua. The engine reloads changes on disk save without process restarts.

Native IPC Pipe

A duplex Named Pipe server lets status bars like YASB read workspace states and dispatch layout actions.

Smart Work Area

Respects system taskbars, auto-hide taskbar modes and custom status bar padding automatically.

Build

Requires MSVC v143 or newer and CMake 3.20+.

git clone https://github.com/ewasion137/QuireTWM.git
cd QuireTWM
cmake -B build -A x64
cmake --build build --config Release
