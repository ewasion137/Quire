Engineered for Deep Multitasking

Direct Win32 APIs, sub-stepped physics integration and hardware-composited HUD.

PHYSICS KINEMATICS

Sub-Stepped Spring Solver

Numerical 4-step Euler integration executes per frame. Zero sudden teleports, zero dropped frames on high-refresh panels.

DIRECTX ENGINE

Direct2D Native Overlay

Borders, idle glow states, Alt+Tab previews and launchers are hardware rendered via DirectWrite and Direct2D surfaces.

EXTENSIBILITY

Pure Lua 5.4 Runtime

Hotkeys, layout logic, custom window hooks and launcher scripts execute in a sandbox with instant file-watcher reloading.

PROCESS SAFETY

Coordinate Parking

Offscreen clients are cloaked with DwmSetWindowAttribute and safely restored on exit without corrupting window coordinates.

Ergonomic Keybindings

Low-latency navigation bindings pre-configured in config.lua
